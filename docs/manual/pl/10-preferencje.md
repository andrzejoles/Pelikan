# Preferencje

- **Ogólne** — tryb sesji (Multi/Dual), wygląd (jasny, ciemny, jak system), język interfejsu, pliki ostatnio używane.
- **SQL Window** — wykonywanie (AutoSelect, potwierdzenia), wyniki (liczba pobieranych wierszy, formaty dat i liczb),
  DBMS_OUTPUT.
- **Edytor** — czcionka, wcięcia, podświetlanie, podpowiedzi, analiza kodu w czasie pisania.
- **Formater** — wielkość liter słów kluczowych, wcięcia, łamanie list, wyrównanie.
- **Klawiatura** — profil skrótów (PL/SQL Developer albo macOS) i własne skróty dla każdej komendy.
- **Oracle** — Instant Client, Oracle Net i Oracle Wallet, ochrona zapisanych haseł (Touch ID), potwierdzanie zmian na
  produkcji, ostrzeżenia kompilatora, wersja dokumentacji dla F1.
- **Agenci** — programy agentów, uprawnienia, tryb ścisły, dziennik.

Rozdział **Skróty klawiszowe** w tym oknie pomocy wylicza wszystkie komendy z bieżącymi skrótami.

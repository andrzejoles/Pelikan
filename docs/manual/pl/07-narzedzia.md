# Narzędzia

- **Session Browser** — sesje bazy z filtrami, bieżącym SQL, blokadami i statystykami; zabijanie sesji po potwierdzeniu.
- **Porównania** — obiektów między schematami i bazami (skrypt wyrównujący), danych tabel, tekstu z plikiem lub
  źródłem w bazie, a także **Database Diff** z koszykiem zmian do wdrożenia.
- **Eksport i import** — eksport obiektów do skryptów DDL, eksport i import tabel (SQL, format własny), Text Importer i
  import z Excela z mapowaniem kolumn, kreator importu, kopiowanie schematu, przenoszenie danych między połączeniami.
- **Data Generator** — dane testowe według wzorców, list i zależności master/detail.
- **Raporty** — własne raporty SQL z parametrami i układem, raporty predefiniowane (słownik danych) z wykresami.
- **Query Builder** i **diagramy** — budowanie zapytań przez przeciąganie tabel (złączenia z kluczy obcych) i diagramy
  ER z bazy.
- **DBMS Scheduler**, **Event Monitor** (DBMS_ALERT, DBMS_PIPE), **Load Tester**, **Test Manager**.
- **Notatnik SQL** — komórki SQL/PL/SQL i Markdown, wyniki i wykresy zapisywane w pliku.
- **Panel DBA** — przestrzenie tabel, parametry, użytkownicy, Instance Viewer; raporty AWR, ASH, ADDM, SQL Monitor i SQL
  Tuning Advisor (za deklaracją licencji, zob. *Połączenia*).
- **Oracle 23ai** — widoki dualności JSON, moduły MLE (także debugowanie po wykonaniu), podgląd danych przestrzennych,
  ORDS.
- **Projekty i worksety** — projekt grupuje pliki i obiekty z buildem; workset zapamiętuje otwarte okna (także
  niezapisane zmiany) między uruchomieniami.
- **Makra**, **historia schowka**, **Special Copy**, zadania **To-Do**, **przeglądarka plików z Git**.
- **Zadania lokalne** — cykliczne skrypty i eksporty uruchamiane, gdy Pelikan działa.

Pomoc kontekstowa **F1** otwiera dokumentację Oracle dla słowa pod kursorem: kodu błędu, pakietu, widoku słownika albo
polecenia SQL. Wersję dokumentacji wybierasz w **Preferencje › Oracle**.

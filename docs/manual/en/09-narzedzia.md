# Tools

- **Session Browser** — database sessions with filters, current SQL, locks and statistics; killing a session after
  confirmation.
- **Comparisons** — of objects between schemas and databases (synchronization script), of table data, of text with a
  file or a source in the database, plus **Database Diff** with a basket of changes to deploy.
- **Export and import** — exporting objects to DDL scripts, exporting and importing tables (SQL, native format), Text
  Importer and Excel import with column mapping, an import wizard, schema copy, moving data between connections.
- **Data Generator** — test data based on patterns, lists and master/detail dependencies.
- **Reports** — your own SQL reports with parameters and layout, predefined (data dictionary) reports with charts.
- **Query Builder** and **diagrams** — building queries by dragging tables (joins from foreign keys) and ER diagrams
  from the database.
- **DBMS Scheduler**, **Event Monitor** (DBMS_ALERT, DBMS_PIPE), **Load Tester**, **Test Manager**.
- **SQL notebook** — SQL/PL/SQL and Markdown cells, with results and charts saved in the file.
- **DBA panel** — tablespaces, parameters, users, Instance Viewer; AWR, ASH, ADDM, SQL Monitor and SQL Tuning Advisor
  reports (after a license declaration, see *Connections*).
- **Oracle 23ai** — JSON relational duality views, MLE modules (including post-execution debugging), spatial data
  preview, ORDS.
- **Projects and worksets** — a project groups files and objects with a build; a workset remembers open windows
  (including unsaved changes) between launches.
- **Macros**, **clipboard history**, **Special Copy**, **To-Do** items, **File Browser with Git**.
- **Local jobs** — recurring scripts and exports that run while Pelikan is running.

Context help **F1** opens the Oracle documentation for the word under the cursor: an error code, a package, a
dictionary view or a SQL statement. You choose the documentation version in **Preferences › Oracle**.

# Preferences

- **General** — session mode (Multi/Dual), appearance (light, dark, system), interface language, recently used files.
- **SQL Window** — execution (AutoSelect, confirmations), results (number of rows fetched, date and number formats),
  DBMS_OUTPUT.
- **Editor** — font, indentation, highlighting, suggestions, code analysis as you type.
- **Formatter** — keyword case, indentation, list wrapping, alignment.
- **Keyboard** — shortcut profile (PL/SQL Developer or macOS) and custom shortcuts for every command.
- **Oracle** — Instant Client, Oracle Net and Oracle Wallet, protection of saved passwords (Touch ID), confirming changes
  in production, compiler warnings, documentation version for F1.
- **Agents** — agent programs, privileges, strict mode, log.

The **Keyboard shortcuts** chapter in this help window lists all commands with their current shortcuts.

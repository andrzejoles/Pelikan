# Herramientas

- **Session Browser**: sesiones de la base de datos con filtros, SQL actual, bloqueos y estadísticas; finalización de
  sesiones previa confirmación.
- **Comparaciones**: de objetos entre esquemas y bases de datos (script de sincronización), de datos de tablas, de texto
  con un archivo o con el código fuente de la base de datos, además de **Database Diff** con una cesta de cambios para
  desplegar.
- **Exportación e importación**: exportación de objetos a scripts DDL, exportación e importación de tablas (SQL,
  formato propio), Text Importer e importación desde Excel con asignación de columnas, asistente de importación, copia
  de esquemas, traspaso de datos entre conexiones.
- **Data Generator**: datos de prueba según patrones, listas y dependencias maestro/detalle.
- **Informes**: informes SQL propios con parámetros y diseño, informes predefinidos (diccionario de datos) con gráficos.
- **Query Builder** y **diagramas**: creación de consultas arrastrando tablas (combinaciones a partir de claves
  foráneas) y diagramas ER de la base de datos.
- **DBMS Scheduler**, **Event Monitor** (DBMS_ALERT, DBMS_PIPE), **Load Tester**, **Test Manager**.
- **Cuaderno SQL**: celdas SQL/PL/SQL y Markdown; los resultados y gráficos se guardan en el archivo.
- **Panel DBA**: tablespaces, parámetros, usuarios, Instance Viewer; informes AWR, ASH, ADDM, SQL Monitor y SQL
  Tuning Advisor (previa declaración de licencia, véase *Conexiones*).
- **Oracle 23ai**: vistas de dualidad JSON, módulos MLE (también depuración posterior a la ejecución), vista previa de
  datos espaciales, ORDS.
- **Proyectos y worksets**: un proyecto agrupa archivos y objetos con un build; un workset recuerda las ventanas
  abiertas (también los cambios sin guardar) entre ejecuciones.
- **Macros**, **historial del portapapeles**, **Special Copy**, tareas **To-Do**, **explorador de archivos con Git**.
- **Trabajos locales**: scripts y exportaciones periódicos que se ejecutan mientras Pelikan está abierto.

La ayuda contextual **F1** abre la documentación de Oracle para la palabra bajo el cursor: un código de error, un
paquete, una vista del diccionario o una sentencia SQL. La versión de la documentación se elige en
**Preferencias › Oracle**.

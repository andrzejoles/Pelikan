# Preferencias

- **General**: modo de sesión (Multi/Dual), apariencia (clara, oscura, como el sistema), idioma de la interfaz, archivos
  usados recientemente.
- **SQL Window**: ejecución (AutoSelect, confirmaciones), resultados (número de filas obtenidas, formatos de fecha y
  número), DBMS_OUTPUT.
- **Editor**: fuente, sangría, resaltado, sugerencias, análisis de código mientras escribes.
- **Formateador**: mayúsculas y minúsculas de las palabras clave, sangría, división de listas, alineación.
- **Teclado**: perfil de atajos (PL/SQL Developer o macOS) y atajos propios para cada comando.
- **Oracle**: Instant Client, Oracle Net y Oracle Wallet, protección de las contraseñas guardadas (Touch ID),
  confirmación de cambios en producción, advertencias del compilador, versión de la documentación para F1.
- **Agentes**: programas de agentes, privilegios, modo estricto, registro.

El capítulo **Atajos de teclado** de esta ventana de ayuda enumera todos los comandos con sus atajos actuales.

# Інструменти

- **Session Browser** — сеанси бази з фільтрами, поточним SQL, блокуваннями й статистикою; завершення сеансу після
  підтвердження.
- **Порівняння** — об'єктів між схемами й базами (скрипт вирівнювання), даних таблиць, тексту з файлом або джерелом
  у базі, а також **Database Diff** із кошиком змін для розгортання.
- **Експорт та імпорт** — експорт об'єктів у скрипти DDL, експорт та імпорт таблиць (SQL, власний формат), Text
  Importer та імпорт з Excel зі зіставленням стовпців, майстер імпорту, копіювання схеми, перенесення даних між
  з'єднаннями.
- **Data Generator** — тестові дані за шаблонами, списками й залежностями master/detail.
- **Звіти** — власні звіти SQL з параметрами й макетом, попередньо визначені звіти (словник даних) з діаграмами.
- **Query Builder** і **діаграми** — побудова запитів перетягуванням таблиць (з'єднання за зовнішніми ключами) і
  ER-діаграми з бази.
- **DBMS Scheduler**, **Event Monitor** (DBMS_ALERT, DBMS_PIPE), **Load Tester**, **Test Manager**.
- **Блокнот SQL** — комірки SQL/PL/SQL і Markdown, результати й діаграми зберігаються у файлі.
- **Панель DBA** — табличні простори, параметри, користувачі, Instance Viewer; звіти AWR, ASH, ADDM, SQL Monitor і SQL
  Tuning Advisor (після декларації ліцензії, див. *З'єднання*).
- **Oracle 23ai** — представлення подвійності JSON, модулі MLE (зокрема налагодження після виконання), перегляд
  просторових даних, ORDS.
- **Проєкти та Workset-и** — проєкт групує файли й об'єкти зі збиранням; Workset запам'ятовує відкриті вікна (зокрема
  незбережені зміни) між запусками.
- **Макроси**, **історія буфера обміну**, **Special Copy**, завдання **To-Do**, **переглядач файлів із Git**.
- **Локальні завдання** — періодичні скрипти й експорти, що запускаються, поки працює Pelikan.

Контекстна довідка **F1** відкриває документацію Oracle для слова під курсором: коду помилки, пакета, представлення
словника або команди SQL. Версію документації вибирають у **Параметри › Oracle**.

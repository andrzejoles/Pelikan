# Program Window і Object Browser

## Object Browser

Дерево об'єктів поточної схеми (або вибраної у фільтрі) з теками за типом: таблиці, представлення, пакети, типи,
тригери, послідовності, а на 23ai також модулі MLE і домени. Контекстне меню об'єкта відкриває його вихідний код,
показує опис, DDL, залежності, дані, дає змогу скомпілювати об'єкт або видалити його. Недійсні об'єкти позначено.

## Program Window

Program Window редагує код PL/SQL: пакети (специфікація й тіло на окремих вкладках), процедури, функції, типи й
тригери. **Виконати** (F8) компілює код у базі, а помилки компіляції з'являються під редактором — клацання переносить
до рядка. Структура коду (Code Contents) показує будову одиниці, а **Перейти до оголошення** переносить до місця
оголошення ідентифікатора.

Редактор підказує назви таблиць, стовпців, пакетів та їхніх елементів, згортає блоки, підсвічує пари `BEGIN`/`END`,
форматує код (**Форматувальник**) відповідно до налаштувань і зберігає локальну історію версій файлу. Шаблони
вставляють готові фрагменти коду.

## Аналіз коду

Під час введення Pelikan підкреслює невідомі таблиці, стовпці й псевдоніми та вказує на проблеми: невикористані
змінні, код після `RETURN`, `UPDATE`/`DELETE` без `WHERE`, неявні перетворення. **Find Usages** шукає використання
об'єкта в базі та файлах проєкту, а **Перейменувати** показує попередній перегляд змін перед застосуванням.

## Файли й кодування

Файли зберігають своє кодування (UTF-8, ISO-8859-2, Windows-1250) і закінчення рядків. Символ, який неможливо записати
в кодуванні файлу, блокує збереження з точним зазначенням місця — змінити кодування можна лише явно
(**Файл › Кодування файлу**).

# Агенти ШІ

Pelikan надає інструменти агентам ШІ, запущеним у терміналі (Claude Code, Codex, Grok, Antigravity), через сервер MCP,
доступний лише для відповідного сеансу. Агент працює в **панелі агента** поруч із вікнами.

## Правила безпеки

- Агент бачить з'єднання лише за назвою (псевдонімом) — ніколи паролі, адреси чи імена користувачів.
- Агент має **власний сеанс бази** (позначений у V$SESSION), за потреби через проксі-користувача з обмеженими
  привілеями. Запити він виконує в транзакції лише для читання, з обмеженнями кількості рядків і часу.
- Зміни (DML, DDL, компіляція) потребують **вашої згоди** у вікні згоди з попереднім переглядом команди й об'єктів,
  яких вона стосується. DML залишається незафіксованим, доки ви не погодитеся на COMMIT.
- На продуктивних з'єднаннях агент має лише читання. Агент не має доступу до Command Window, команд операційної
  системи, налагоджувача чи звітів AWR/ASH.
- Вказані стовпці можна маскувати в результатах для агента.
- **Скасувати сеанс агента** повертає об'єкти, змінені агентом, до стану перед змінами (з виявленням конфліктів).

Привілеї, список програм і журнал дій містяться в **Параметри › Агенти**.

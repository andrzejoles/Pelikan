# Pro*C: віддалене збирання через SSH

Pelikan збирає програми Pro*C на сервері (наприклад, AIX) через SSH: отримує зміни з репозиторію Git до working copy
на сервері, запускає `make`, установлює бінарні файли й веде історію розгортань із можливістю відкоту.

## Цілі SSH

У **Цілі SSH** ви визначаєте сервер: хост, порт, користувача, автентифікацію (ключ, агент SSH або пароль), кодування,
середовище (ORACLE_HOME, LIBPATH, PATH), базовий каталог, каталог резервних копій, гілку й команду збирання. Пароль SSH
або парольна фраза ключа потрапляє до В'язки ключів, а визначення цілей зберігаються без секретів. Цілі позначають як
UAT або PROD.

**Тестувати** перевіряє вхід, версію системи та сервера SSH, доступність `make`, `git`, `compress`/`gzip`, гілку й
чистоту working copy, а також можливість запису в каталоги.

## Розгортання

Розгортання виконує послідовно: блокування (одне розгортання водночас), перевірку working copy (ручні зміни на сервері
зупиняють розгортання), `git pull --ff-only`, резервну копію бінарних файлів, `make`, установлення й запис до історії.
Pelikan ніколи не виконує на сервері merge чи reset. Перед розгортанням на PROD потрібно ввести назву цілі.

Консоль показує кроки з часом і результатом; помилки компілятора Pro*C (`PCC-…`) та IBM XL C (`1506-…`) клікабельні й
відкривають файл у місці помилки. **Стоп** перериває розгортання й завжди знімає блокування. **Відкотити** відновлює
попередні бінарні файли або вибрану копію.

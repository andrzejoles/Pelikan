# З'єднання та безпека паролів

## Визначення з'єднання

З'єднання має назву, теку, користувача, базу (EZConnect `host:port/usługa`, `tcps://…` або псевдонім із
`tnsnames.ora`), роль (Normal, SYSDBA…), за потреби проксі-користувача, редакцію (EBR) і середовище: для розробників,
тестове або продуктивне. Продуктивні з'єднання мають попереджувальний колір, а команди, що змінюють дані, потребують
там підтвердження.

З'єднання може бути **лише для читання** — тоді Pelikan відхиляє DML, DDL і PL/SQL, перш ніж вони потраплять до бази.

## Паролі

Паролі зберігаються виключно у **В'язці ключів** macOS (вхід, без синхронізації з iCloud) і ніколи не потрапляють до
файлів, журналів чи аргументів процесів. Пароль зберігається лише після вдалого з'єднання і лише тоді, коли ви
позначите **Запам'ятати пароль у В'язці ключів**.

У **Параметри › Oracle** можна ввімкнути **Вимагати Touch ID або пароль Mac перед використанням збереженого пароля** —
тоді Pelikan запитуватиме один раз на з'єднання під час роботи застосунку.

## Oracle Wallet

Pelikan підтримує два типи гаманців:

- **сховище паролів** (Secure External Password Store) — вхід `/@alias` без введення пароля; каталог гаманця
  вказують у **Параметри › Oracle › Oracle Net і Oracle Wallet**, а в з'єднанні вибирають автентифікацію
  *Oracle Wallet*. Поле «База» має точно збігатися з псевдонімом, збереженим у гаманці;
- **гаманець TLS** (наприклад, Autonomous Database) — каталог гаманця задають у визначенні з'єднання; архів ZIP із
  порталу можна розпакувати кнопкою **Імпортувати ZIP…**.

## Інші способи автентифікації

- **Зовнішня** (Kerberos, операційна система).
- **Microsoft Entra ID** — Instant Client 23 відкриває браузер для входу й сам передає токен базі; Pelikan токена не
  бачить і не зберігає.
- **Токен OAuth2 з файлу** — токен, заздалегідь підготовлений зовнішнім інструментом.
- **Тунель SSH** — з'єднання через проміжний сервер (ключ або агент SSH).

## Ліцензії пакетів Oracle

Звіти AWR, ASH, ADDM, SQL Monitor і SQL Tuning Advisor потребують платних пакетів Oracle Diagnostics/Tuning Pack.
Під час першого використання Pelikan запитує, чи має база ліцензію, і запам'ятовує відповідь у визначенні з'єднання.

# Параметри

- **Загальні** — режим сеансу (Multi/Dual), вигляд (світлий, темний, як у системі), мова інтерфейсу, нещодавні файли.
- **SQL Window** — виконання (AutoSelect, підтвердження), результати (кількість рядків, що отримуються, формати дат і
  чисел), DBMS_OUTPUT.
- **Редактор** — шрифт, відступи, підсвічування, підказки, аналіз коду під час введення.
- **Форматувальник** — регістр ключових слів, відступи, перенесення списків, вирівнювання.
- **Клавіатура** — профіль скорочень (PL/SQL Developer або macOS) і власні скорочення для кожної команди.
- **Oracle** — Instant Client, Oracle Net і Oracle Wallet, захист збережених паролів (Touch ID), підтвердження змін на
  продуктивних базах, попередження компілятора, версія документації для F1.
- **Агенти** — програми агентів, привілеї, суворий режим, журнал.

Розділ **Клавіатурні скорочення** в цьому вікні довідки перелічує всі команди з поточними скороченнями.
